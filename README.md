# Korenkov School — Mini App v2

Полная версия личного кабинета: ученик + учитель, оплата, материалы, группы.

## Что нового по сравнению с v1
- Группы учеников (ОГЭ 2026, ЕГЭ 2026, Алгебра 9, Геометрия, ТВ)
- История платежей и тариф на странице "Оплата"
- Видео-разборы ДЗ и записи занятий на странице "Материалы"
- ДЗ с фильтрами (Все / Сдано / Не сдано / Проверяется) и кнопкой тренажёра
- Панель учителя: Ученики (открыть/закрыть доступ кликом), Расписание, ДЗ (отметить проверенным), Аналитика, Настройки/Группы
- Тёмная фиолетовая тема

## Установка
1. Supabase → SQL Editor → выполнить `supabase/schema_v2.sql` (добавляет новые таблицы поверх старых, безопасно)
2. Загрузить эти файлы в репозиторий `korenkov-school-miniapp` на GitHub (заменить всё содержимое)
3. Vercel сам передеплоит автоматически при пуше в main

## Как открыть панель учителя
Ссылка вида `https://ваш-сайт.vercel.app/?teacher=1` — либо пометьте свою запись
в таблице `students` полем `is_teacher = true`, тогда панель откроется всегда для вас.

## Наполнение данными
- Занятия → таблица `lessons` (поля subject, topic, group_id)
- ДЗ → таблица `homework` (total_tasks, correct_tasks, trainer_url)
- Материалы (видео/конспекты) → таблица `materials`
- Оплаты → таблицы `payments` и `subscription_plans`
- Группы учеников → таблица `student_groups`
