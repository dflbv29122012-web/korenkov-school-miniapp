# Korenkov School — Mini App

## Установка обновления

1. **Supabase** → SQL Editor → New query → выполнить файл
   `supabase/ВЫПОЛНИТЬ_В_SUPABASE.sql` целиком → Run

2. **GitHub** → в репозитории korenkov-school-miniapp:
   - зайти в папку `src` → удалить всё внутри
   - зайти ВНУТРЬ пустой папки `src` → Add file → Upload files
   - перетащить содержимое папки `src` из этого архива
   - Commit changes

3. Vercel передеплоит автоматически (1-2 минуты).

## Что умеет панель учителя

- **Ученики** — добавление ученика, открытие/закрытие доступа, задолженность, привязка к группам
- **Расписание** — добавление занятий: индивидуальных (для ученика) и групповых (для всей группы)
- **ДЗ** — задать ДЗ с прикреплением фото или файла, отметить проверенным
- **Материалы** — видео-разборы, записи занятий (загрузка файла или ссылка), конспекты (PDF/фото)
- **Ещё** — аналитика, создание и удаление групп, привязка учеников к группам

## Как открыть панель учителя

В таблице `students` у своей записи поставить `is_teacher = true`.
Либо открыть приложение по ссылке с `?teacher=1` на конце.
